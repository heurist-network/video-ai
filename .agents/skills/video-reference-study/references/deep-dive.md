# Read the scene as a coordinated system

Start with the viewing task, not an effects catalog. Name the change in understanding and inspect enough of the incoming and outgoing scene to see the handoff.

## Evidence to capture

For a selected excerpt, reconstruct phases and events with approximate local intervals:

| Layer | What changes | Why it matters | Related action | What stays legible |
| --- | --- | --- | --- | --- |
| Subject | Grid units progress | Demonstrates process | Counter changes from the same visible progress | Spatial arrangement |
| Measurement | Completed count rises | Quantifies process | Units and label | Unit/count correspondence |
| Annotation | Words and leader assemble | Identifies a referent | Process continues underneath | Label and target association |
| Framing | View enlarges/repositions | Shifts explanatory scale | Old legend exits; local label starts | Recognizable anchor |

These are examples, not required tracks. An elegant focus dial may need only selection and emphasis. Describe true holds as holds. A static dotted background is not a motion layer merely because it adds texture. Shared camera/group motion does not prove independent movement by each child.

Distinguish:

- Entrance, internal development and exit. “Enter → hold → exit” may be sufficient for a punctuation beat, but does not explain a complex mechanism.
- Concurrent visibility and concurrent change. Record actual overlap windows, not the whole lifetime of an object.
- Temporal coincidence and semantic coupling. State whether two changes depict a shared process, cause and response, hierarchy shift, contrast or reference binding.
- Persistent identity and replacement. Follow geometry, content and spatial role across the boundary; a similar-looking new card is not automatically the same evolving object.
- What pixels establish and what implementation might produce them. Apparent depth/reframing is observable; a 3D camera, GSAP curve or underlying data model is not recoverable from appearance alone.

Keep the dominant attention target explicit by phase. Multiple motions should support a readable hierarchy, not compete at equal intensity. Note scale, color exclusivity, contrast, position and timing—not just effects.

## Verify the dangerous moments

Inspect before, during and after each handoff, not only settled poses. Slow inspection diagnoses a transition; normal speed judges whether it reads. Examine text anchoring, baselines, wrapping, word replacement, amount trajectories, leader attachment, counter consistency, and changes to the group's coordinate frame. A useful sequence can still contain a rough implementation; say so.

Dense timing is evidence, not an invitation to false precision. Use approximate intervals when source sampling is insufficient. Model confidence is not verification. If an observed action contradicts the model's generic advice, preserve the observed mechanism and correct the advice.

## Finish each deep dive

Include the source range, selection rationale, observable phase progression, event timeline, explanation of meaningful overlaps, attention handoff, stable invariants, representative frames and a reusable build prompt. End with a concrete failure mode, not generic praise. Keep the detailed uncertainty attached to the claim it limits.
